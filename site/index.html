    Practise on your own machine

    Run the AWS examples

    Each folder in the repository is a working example. Real AWS resources cost money: destroy them when you finish.

    # 1. Get the examples
git clone https://github.com/SandeepKomal/Terraform-HashiCorp.git
cd Terraform-HashiCorp/tf-vpc

# 2. Check who you are in AWS
aws sts get-caller-identity

# 3. The workflow
terraform init
terraform fmt -check
terraform validate
terraform plan -out=tfplan
terraform apply tfplan

# 4. Clean up
terraform destroy

    Terraform or OpenTofu?

    Either works for everything here.

    OpenTofu is an open-source fork of Terraform, started in 2023 after HashiCorp moved Terraform to the Business Source License, and maintained under the Linux Foundation.

    Its tofu command takes the same commands and HCL for nearly everything on this site: tofu init, tofu plan, tofu apply. Messages say OpenTofu instead of Terraform, and the newest features of each have started to differ, so check its documentation for those.
