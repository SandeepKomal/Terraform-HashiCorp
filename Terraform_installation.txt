# Terraform installation

## Amazon Linux / RHEL-compatible systems

Install the HashiCorp repository and Terraform using the current HashiCorp installation instructions for your distribution.

After installation:

    terraform version

## Basic workflow

Run these commands from one of the example directories:

    terraform init
    terraform fmt
    terraform validate
    terraform plan
    terraform apply

Review the plan before applying changes.

Use:

    terraform destroy

when you are finished with temporary learning resources.

Do not store AWS credentials, passwords, Terraform state, or other secrets in the repository.
